# Why AWS CLI? Why Not Just Terminal?

This document explains why AWS CLI is required when working with AWS and tools like AWS SAM, and why the terminal alone is not enough.

---

## 1. What Is a Terminal?

A **terminal** (Command Prompt, PowerShell, Bash) is just an interface to:

- Type commands
- Run programs installed on your machine
- Display output

The terminal itself:
- Does **not** understand AWS
- Does **not** know how to talk to cloud services
- Only executes local commands

Example: bash dir

### Short answer

    Terminal ≠ AWS
    
    Terminal = just a window to type commands
    
    AWS CLI = a program that knows how to talk to AWS
    
    Terminal is like a phone 📱
    AWS CLI is like WhatsApp installed on that phone
    
    Without WhatsApp, the phone can’t send WhatsApp messages.

# How CMD Knows a Command Is for AWS (and Runs AWS CLI)

This document explains **how Windows CMD understands which commands belong to AWS**, and how it passes them to the AWS CLI.

---

## 1. Important Truth (Read First)

**CMD does NOT understand AWS.**  
There is **no AWS terminal**.

CMD only:
- Reads what you type
- Finds a program with that name
- Runs it

All AWS knowledge lives inside **AWS CLI**.
