# AWS SAM Local Development: Why CLI, Terminal, and Docker Are Needed

This document explains the prerequisites and reasoning behind using AWS CLI, terminal, and Docker for AWS SAM development and local Lambda debugging.

## 1. Why AWS CLI? Why Not Just Terminal?

### 1.1 What Is a Terminal?

A **terminal** (Command Prompt, PowerShell, Bash) is just an interface to:

- Type commands
- Run programs installed on your machine
- Display output

The terminal itself:

- Does **not** understand AWS
- Does **not** know how to talk to cloud services
- Only executes local commands
