# STEP 0: Prerequisites (do once)

Make sure these work:

```bash
aws --version
sam --version
docker --version
node --version
```

# STEP 1: Download Lambda code from AWS

### Option A: From AWS Console (easy)

1. Open **AWS Lambda Console**
2. Open your Lambda function
3. Click **Code → Download**
4. Extract zip

You’ll get something like:

```
index.js
or
app.js
or
src/...
```

📌 This zip **does NOT include layers** (this is expected).

---

### Option B: Using AWS CLI (recommended)

```bash
aws lambda get-function \
  --function-name YOUR_FUNCTION_NAME \
  --query 'Code.Location' \
  --output text
```

Copy the URL → download → unzip.

---

# STEP 2: Create local project folder

```bash
mkdir my-lambda-local
cd my-lambda-local
```

Now organize properly 👇

```
my-lambda-local/
│
├── function/
│   └── app.js
│
├── layers/
├── events/
├── template.yaml
└── env.json
```

# STEP 3: Move Lambda code

Put your downloaded Lambda file here:

```
function/app.js
```

Example Lambda (unchanged):

```js
exports.handler = async (event) => {
  return {
    statusCode: 200,
    body: "Lambda works"
  };
};
```

⚠️ Do NOT modify working Lambda code yet.

---

# STEP 4: Find which layers your Lambda uses

Run:

```bash
aws lambda get-function-configuration \
  --function-name YOUR_FUNCTION_NAME
```

Look for:

```json
"Layers": [
  {
    "Arn": "arn:aws:lambda:ap-south-1:123456789012:layer:common-layer:3"
  }
]
```

✍️ Note:

* Layer name: `common-layer`
* Version: `3`

---

# STEP 5: Download the layer from AWS

### Get layer download URL

```bash
aws lambda get-layer-version \
  --layer-name common-layer \
  --version-number 3
```

You’ll see:

```json
"Content": {
  "Location": "https://awslambda-....amazonaws.com/..."
}
```

---

### Download & extract layer

```bash
curl -o layer.zip "PASTE_LOCATION_URL"
unzip layer.zip -d layers/common
```

Now verify:

```
layers/common/nodejs/node_modules
```

✅ This is critical.

---

# STEP 6: Create SAM template

### `template.yaml`

```yaml
AWSTemplateFormatVersion: '2010-09-09'
Transform: AWS::Serverless-2016-10-31

Resources:
  CommonLayer:
    Type: AWS::Serverless::LayerVersion
    Properties:
      LayerName: common-layer
      ContentUri: layers/common
      CompatibleRuntimes:
        - nodejs18.x

  TestFunction:
    Type: AWS::Serverless::Function
    Properties:
      FunctionName: test-local-lambda
      Runtime: nodejs18.x
      Handler: function/app.handler
      CodeUri: .
      Layers:
        - !Ref CommonLayer
      Timeout: 30
```

⚠️ Handler path **must match your file**.

# STEP 7: Environment variables (if Lambda uses any)

### `env.json`

```json
{
  "TestFunction": {
    "NODE_ENV": "local"
  }
}
```

If your Lambda doesn’t use env vars, this is still safe.

# STEP 8: Create test event

### `events/event.json`

```json
{
  "test": "hello"
}
```

---

# STEP 9: Build Lambda (VERY IMPORTANT)

```bash
sam build
```

If this fails:

* Layer structure is wrong
* Handler path is wrong
* Node version mismatch

Fix before moving on.

---

# STEP 10: Run Lambda locally 🎉

### Invoke directly

```bash
sam local invoke TestFunction \
  --env-vars env.json \
  -e events/event.json
```

You should see:

* Console logs
* Lambda response

If it matches AWS → ✅ success.

---

# STEP 11: Verify layer is actually used

Add temporarily:

```js
console.log(require.resolve("axios"));
```

Expected output:

```
/opt/nodejs/node_modules/axios/index.js
```

If yes → layer is loaded correctly.
