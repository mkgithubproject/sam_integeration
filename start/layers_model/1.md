# STEP 2: Create Lambda Layer (shared packages)

```bash
cd layers/common/nodejs
npm init -y
npm install axios lodash
```

📌 This installs packages **only in the layer**, not in Lambda.

---

# STEP 3: Write Lambda code (simple example)

### `functions/hello/app.js`

```js
const axios = require("axios"); // comes from layer

exports.handler = async (event) => {
  console.log("ENV:", process.env.APP_ENV);

  const res = await axios.get(
    "https://jsonplaceholder.typicode.com/todos/1"
  );

  return {
    statusCode: 200,
    body: JSON.stringify({
      message: "Hello from Lambda",
      data: res.data
    })
  };
};
```

No magic. This is **real Lambda code**.

# STEP 4: SAM template (connect everything)

### `template.yaml`

```yaml
AWSTemplateFormatVersion: '2010-09-09'
Transform: AWS::Serverless-2016-10-31

Resources:
  CommonLayer:
    Type: AWS::Serverless::LayerVersion
    Properties:
      LayerName: common-layer
      ContentUri: layers/common
      CompatibleRuntimes:
        - nodejs18.x

  HelloFunction:
    Type: AWS::Serverless::Function
    Properties:
      FunctionName: hello-function
      Runtime: nodejs18.x
      Handler: functions/hello/app.handler
      CodeUri: .
      Layers:
        - !Ref CommonLayer
      Events:
        Api:
          Type: Api
          Properties:
            Path: /hello
            Method: get
```

✔ Lambda
✔ Layer
✔ API
✔ Local & AWS compatible

```bash
sam build
```

---

# STEP 8: Run locally (2 ways)

## Option A: API mode (recommended for beginners)

```bash
sam local start-api --env-vars env.json
```

Open browser:

```
http://localhost:3000/hello
```

---

## Option B: Direct invoke

```bash
sam local invoke HelloFunction \
  --env-vars env.json \
  -e events/event.json
```

---

# STEP 9: Debug (optional but powerful)

```bash
sam local invoke HelloFunction \
  --env-vars env.json \
  -e events/event.json \
  -d 5858
```

Attach VS Code debugger → breakpoints work 🔥

# STEP 10: GitHub tracking (IMPORTANT)

### `.gitignore`

```gitignore
.aws-sam/
node_modules/
.env
```

### What to commit ✅

* Lambda code
* Layer `package.json`
* SAM template
* env.json (sample or dev)

### What NOT to commit ❌

* `.aws-sam`
* local `.env`
* AWS credentials
